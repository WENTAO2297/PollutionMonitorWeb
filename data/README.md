# Data Directory

The active data in this repository support a simulation-based proof of concept. They do not contain real NOx measurements from environmental monitoring stations.

## `sample/`

### `vehicle_emissions_2026.csv`

This file contains 483 vehicle records and the following fields:

- model year;
- city, highway, and combined fuel consumption;
- combined fuel economy;
- CO2 emissions and rating;
- Smog Rating.

`scripts/generate_simulation_data.py` uses Smog Rating in the active NOx proxy calculation. CO2 fields are retained as source vehicle metadata, and an intermediate CO2 total may be calculated by the script, but CO2 is not used by the active NOx proxy label, written to the current processed dataset, or provided as a model input.

The file is an input sample, not a record of vehicles observed in Xuhui District. The original data source and redistribution terms should be verified and cited before using the dataset outside this educational repository.

## `processed/`

### `shanghai_traffic_simulation.csv`

This is the active model dataset. It contains 2,160 hourly rows generated by `scripts/generate_simulation_data.py`, corresponding to 90 simulated days.

Columns:

| Column | Meaning in this prototype |
| --- | --- |
| `Hour` | Hour of day from 0 to 23 |
| `Traffic_Volume` | Simulated hourly traffic count |
| `Average_Speed` | Simulated average road speed |
| `Temperature` | Simulated temperature with a daily pattern and noise |
| `Humidity` | Simulated humidity with a daily pattern and noise |
| `NOx_Emission` | Simulated target derived mainly from Smog Rating, traffic volume, and congestion assumptions |

The target is not a measured roadside concentration. The displayed NOx values are model-output units from a simulated proxy task and should not be interpreted as calibrated milligrams, concentration measurements, regulatory emission estimates, or official environmental observations.

Because traffic volume and speed are sampled from simplified random distributions without strict physical bounds, the processed file may contain negative traffic flow, overly high speed, or other unrealistic values. These records reflect limitations of the current generator rather than observed traffic conditions.

Running the generator overwrites this file with a new random realization:

```bash
python scripts/generate_simulation_data.py
```

Because the current script does not fix all random seeds, regenerated values will differ.

## Data Used During Online Inference

The Streamlit application may obtain current traffic speed and congestion descriptions from AMap and current weather from Open-Meteo or wttr.in. These API responses are not stored as a versioned dataset here.

Current API data are used only to construct dashboard inputs. They are not used to train the included model.

The 24-hour input required by the model is partially simulated from current conditions, landmark assumptions, time-of-day factors, and random noise. Therefore, API availability does not turn the output into a real monitoring measurement.

## Excluded Historical Data

Unused raw datasets are stored locally under `legacy/data/` and excluded from Git. They are not required for the current application, training script, or evaluation script.
